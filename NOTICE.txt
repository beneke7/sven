Sven Bømwøllen — original game, browser compatibility build

Sven.exe is unchanged. No game rules, menus or animations have been rewritten.
The working Sven.dat uses the same predecoded PCM sound cache as the Mac build.
Images, maps and all other archive members remain byte-identical to the original.
Original game code and artwork retain their original ownership.

Boxedwine 26R1 (GPL-2.0) runs the x86 executable in WebAssembly.
Release and corresponding source:
https://github.com/danoon2/Boxedwine/releases/tag/26R1.0
https://github.com/danoon2/Boxedwine/tree/26R1.0
Unmodified single-threaded runtime and Wine 11 filesystem downloaded from:
https://boxedwine.org/v/26R1/wine11/st/
Unmodified threaded JavaScript and WebAssembly runtime downloaded from:
https://boxedwine.org/v/26R1/wine11/mt/
Runtime file hashes are recorded in build.json.

Wine (LGPL-2.1-or-later) supplies Windows compatibility.
Its 32-bit olepro32.dll is supplied from the same Wine 11.0 build used by
the Mac package, because Boxedwine's minimal filesystem omits it:
https://github.com/Gcenx/macOS_Wine_builds/releases/tag/11.0_1
https://gitlab.winehq.org/wine/wine/-/tree/wine-11.0
https://www.winehq.org/
Full license texts: Boxedwine-LICENSE.txt, Wine-LICENSE.txt, Wine-COPYING.LIB.txt.

cnc-ddraw 7.1.0.0 (MIT) supplies GDI presentation. The browser build uses the
unmodified official release DLL; the Mac app keeps its separate wrapper and
memory-context fix. The original game runs at 640x480 with 16-bit color.
https://github.com/FunkyFr3sh/cnc-ddraw/releases/tag/v7.1.0.0
The full MIT notice is in cnc-ddraw-LICENSE.txt.

coi-serviceworker v0.1.7 (MIT) enables browser isolation for the threaded runtime.
Source commit: 7b1d2a092d0d2dd2b7270b6f12f13605de26f214
https://github.com/gzuidhof/coi-serviceworker/tree/7b1d2a092d0d2dd2b7270b6f12f13605de26f214
The full MIT notice is in coi-serviceworker-LICENSE.txt.

Scores and settings are saved in this browser's site storage. Clearing site
data removes them. The web build does not read or replace Mac game saves.
