Sven Bømwøllen — reconstructed native browser port

This version runs JavaScript directly in the browser with Canvas 2D and Web Audio.
It does not execute Sven.exe and does not include a Windows runtime or CPU emulator.

The original graphics, sound recordings, level layouts, character designs, title
and trademarks retain their original ownership. These materials were imported
from the supplied Sven.dat. PNG conversion preserves the original sprite layout
and color-key transparency. The beam texture and UFO silhouette mask derive from
the original raw bitmap and mask; no replacement artwork was generated.

The supplied executable is the behavioral reference, SHA-256:
3c6b309fbc1993d10fefc7953af10006826729c26e11a340f61f58eba0d662e2

Browser game code is a reconstruction from inspected machine code, recovered
tables and original data. It is not the original game source code. The original
executable and archive are not modified by the import or build tools.

The campaign includes all 20 original level maps, 147 original image definitions
and 61 original sounds. Original frame ordering, pose anchors, interface button
positions and default high scores are recovered from the supplied game files.
build.json records source and release hashes. The development workspace contains
the recovery evidence and binary comparison tests under evidence/native/.

Complete behavioral, timing, visual and audio parity has not been established.
The current reconstruction retains documented limits in special-event rendering
and some original state transitions. Browser scores and controls are stored
locally under sven-native-classic-v1, separately from desktop game saves.

by this notice. Attribution and ownership are unchanged by this browser port.
